¿Qué significa cada estado?
• En línea: el sistema respondió con un código HTTP entre 200 y 399.
• Sin respuesta: hubo un error HTTP o no se pudo completar la consulta.
• Pendiente: el sistema está desactivado o todavía no tiene una comprobación guardada.

Frecuencia: GitHub Actions está configurado para comprobar los sistemas habilitados cada 5 minutos. GitHub puede retrasar las tareas programadas; el panel vuelve a leer el informe cada 60 segundos.
